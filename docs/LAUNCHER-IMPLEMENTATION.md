## 검증 (5칸 메뉴 제거 후)

- 대상 단위 30개 및 전체 단위 198파일 / 2,106개 통과.
- Chromium 컴포넌트 50개 통과: 실제 UI, 공통 메뉴·첫 번째 홈·검색·사진 등록·알림, 320/393/768px 라이트·다크. 서버 액션은 stub이며 실제 DB 저장 검증은 아님.
- TypeScript 통과. 전체 lint는 기존 파일 오류 14개·경고 39개로 실패.
- 스키마 검사 69개 통과·1개 실패: 라이브 DB에 public.member_share_prefs 테이블 누락. 이번 변경에는 DB 수정 없음.
- 공개 Supabase 설정을 gitignored .env.local에 구성하여 로컬 앱 실행. 비밀값은 커밋 대상에서 제외.
- next build 통과. 대상 ESLint 오류 0(기존 경고 1).
- 신규 런처 E2E: mobile-chromium, http://127.0.0.1:3011 빌드된 앱에서 2개 통과(41.7초). 계정 2개 정리 완료. 개발 서버에서는 Next.js 도구 버튼의 홈 클릭 간섭 발생.
- 전체 E2E는 --max-failures=1로 6개 통과·1개 실패·295개 미실행: 기존 오늘만 부위 추가 후 URL 기대 불일치. 해당 실행의 계정 정리는 DB timeout으로 확인하지 못함.
- Android 실기기 미검증. 전체 게이트 실패를 보고한 뒤 사용자가 "너작업만 커밋해"로 예외 커밋 승인(2026-09-21, RULE.md 3절).
