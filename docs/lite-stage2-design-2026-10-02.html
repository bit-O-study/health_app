1. 3개월 목표와 진행률 완료

화면

  • 성장 탭 맨 위 "내 목표" 카드. 비어 있으면 [목표 정하기].
  • 정하기 시트: 종목(내가 해 본 무게 운동 중 볼륨 상위 8개 + 검색) · 목표 무게(예상 1RM, 지금 값 +10%가 미리 채워짐) · 날짜(기본 3개월 뒤, 4주~12개월).
  • 카드: 벤치프레스 82.5 → 100kg · 진행 막대 47% · "지금 속도면 12월 20일쯤 · 목표보다 2주 빠름" 또는 "주 1.2kg씩 올려야 해요".
  • 목표에 닿으면 축하 한 줄 + [다음 목표].

계산(순수 함수 goal-progress.ts)

  • 지금 값 = 그 종목 최근 예상 1RM(성장 탭과 같은 oneRMSeries).
  • 진행률 = (지금 − 시작) ÷ (목표 − 시작). 시작 = 목표를 정한 날의 값(저장).
  • 예상 도달일 = 최근 6주 1RM 기울기(최소제곱)로 직선 연장. 기울기가 0 이하면 "정체 중" → 6번 정체 탈출로 연결.
  • 필요 속도 = (목표 − 지금) ÷ 남은 주.
  • 기록 4번 미만이면 날짜 대신 "기록이 더 쌓이면 알려 드려요".

데이터 · 경계 · 테스트

  • 새 표 lift_goals(id, user_id, exercise_id, start_kg, target_kg, start_date, target_date, achieved_at, created_at) · RLS 본인만. 라이브 DB 적용 + 스키마 동기화 테스트.
  • 무료: 목표 1개(진행률만, 예상 도달일 잠금). 라이트: 목표 3개 + 예상 도달일·필요 속도.
  • 테스트: 진행률·도달일·정체 판정 단위 테스트, 목표 저장 → 성장 탭 표시 E2E.

2. 이번 주 정리 알림 완료

보내는 것

  • 일요일 20시 푸시 한 통: "이번 주 4일 운동 · 볼륨 18,200kg(+12%) · 신기록 1개 · 단백질 채운 날 3일".
  • 누르면 맞춤 운동 › 리포트 탭.
  • 운동 0일인 주는 다그치지 않는 문장: "이번 주는 쉬었어요. 다음 주 첫 운동을 잡아 볼까요?"

어떻게(새 cron 없이)

  • Vercel cron 은 지금 2개로 꽉 차 새로 못 둔다 → 매일 20시(KST)에 도는 /api/cron/daily-reminders 에 "일요일이면 주간 정리"를 붙인다(토요일 부위 균형 알림과 같은 방식).
  • 중복 방지: 기존 sent-log 에 weekly-summary:주 시작일 키.
  • 알림 종류 weekly-summary 추가 → 설정 › 알림에서 끌 수 있게, 야간 금지 시간도 지킴.
  • 대상: 라이트 이상 + 기기 등록 + 그 종류 켜짐. 숫자는 1단계 리포트 계산을 재사용.

테스트: 문장 만들기(운동 0일·신기록 있음 등) 단위 테스트, 일요일에만·라이트에게만·한 번만 보내는지 단위 테스트(기기 발송은 가짜로).

3. 몸 사진 비교 완료

화면

  • 설정 › 기록 › 몸 사진(새 화면) · 맞춤 운동 리포트 탭에 "몸 사진" 카드(최근 2장 나란히).
  • [사진 추가] → 앞·옆·뒤 중 고르고 찍기/고르기 → 날짜(기본 오늘).
  • 비교: 날짜 두 개를 고르면 좌우 나란히(같은 방향끼리), 아래에 그 사이 체중·골격근 변화(체성분 리포트 재사용).
  • 사진마다 지우기. "이 사진은 나만 봐요" 문구 고정.

저장 · 개인정보

  • 새 비공개 버킷 body-photos(체성분 분석지 버킷과 같은 규칙: 본인 폴더만, 공개 URL 없음, 볼 때만 짧은 서명 URL).
  • 기기에서 긴 변 1280px · 약 300KB 로 줄여 올린다(기존 사진 축소 재사용).
  • 표 body_photos(id, user_id, taken_on, pose 앞/옆/뒤, path, created_at) · RLS 본인만 · 계정 삭제 시 함께 삭제.
  • 처리방침에 "몸 사진(선택)" 추가 — 민감할 수 있어 처음 올릴 때 한 번 동의.

경계 · 비용 · 테스트

  • 무료 3장 / 라이트 무제한(남용 방지로 하루 10장).
  • 비용: 1인 월 10장 × 300KB = 3MB → 1인 월 1원 미만.
  • 테스트: 올리기·목록·비교·지우기 E2E, 다른 사람 사진이 안 열리는지 보안 E2E, 무료 4장째 막힘.

5. 아픈 부위 대체 운동 완료

지금 → 바뀌는 것

  • 지금: 오늘 운동 컨디션 카드에 "어깨 운동 2개가 오늘 있어요"라고 알리기만 한다.
  • 라이트: 그 아래 [오늘만 다른 운동으로 바꾸기] → 미리보기 시트에 "숄더 프레스 → 레그 컬"처럼 짝을 보여 주고 적용.
  • 무료: 알림 그대로 + "라이트에서 바로 바꿀 수 있어요" 한 줄.

규칙 · 테스트

  • 대체 후보 = 맞춤 운동 추천(pickExercises) — 이미 아픈 부위·내 헬스장 기구·초급자 제외·회복 중 근육을 거른다. 아픈 운동 수만큼 고른다.
  • 적용 = 아픈 부위 운동을 오늘 계획에서만 빼고 대체 운동을 오늘만 더한다(원칙 2: 내 루틴은 그대로).
  • 새로 필요한 것: 오늘 계획에서 특정 줄만 빼는 '오늘만' 동작 — 오늘 계획(daily_plan)으로 복사한 뒤 그 줄 삭제(기존 오늘만 변경 경로 재사용).
  • 테스트: 짝 고르기 단위 테스트, 적용 후 루틴 불변·오늘 계획만 바뀜 E2E.

6. 정체 탈출 제외 — 이미 무료

정정(2026-10-02): 운동 모드에 이미 무료로 있다 — 오래 정체된 종목에 같은 부위 대체 운동 3개를 오늘만 바꾸기(exercise-substitutes.ts·replaceExerciseTodayOnlyAction), 무게·반복·디로드 제안(overload.ts). 무료에서 빼앗지 않는 원칙대로 라이트 혜택에서 뺐다.

화면

  • 성장 탭에서 이미 "정체"가 붙는 종목(최근 3번 예상 1RM 안 오름, stalledLifts) 아래 [정체 탈출].
  • 방법 3개 중 고르기 → 오늘만 운동 변경으로 적용:
    • 반복 바꾸기: 무게 −10%, 8~12회 3세트
    • 변형 운동: 같은 세부 근육을 강하게 쓰는 다른 종목으로 오늘만 교체(벤치 → 인클라인 덤벨)
    • 세트 추가: 같은 무게로 1세트 더

규칙 · 경계 · 테스트

  • 변형 운동은 세부 근육 점수표로 고른다(같은 주동근 점수 70 이상, 내 헬스장 기구, 초급자 제외). 점수표가 트레이너 검수 전 초안이라는 점은 그대로 안내.
  • 오늘 그 종목이 없으면 "오늘 운동에 더하기"로만.
  • 무료: 정체 표시 그대로 + 잠금 한 줄. 라이트: 탈출 버튼.
  • 5번에서 만드는 '오늘만 한 줄 빼기'를 재사용. 테스트: 변형 고르기 단위 테스트, 적용 E2E(루틴 불변).

위험과 대응

위험대응
몸 사진은 민감 정보비공개 버킷·서명 URL·본인 RLS, 처음 올릴 때 동의, 처리방침 갱신, 계정 삭제 시 함께 삭제. 보안 E2E 필수.
주간 알림이 귀찮음주 1회만, 설정에서 끄기, 야간 금지 지킴, 운동 안 한 주에 다그치지 않는 문장.
예상 도달일이 틀림기록 4번 미만이면 날짜 대신 안내 문장. 항상 "예상"이라고 표기.
대체·변형 운동이 부적절세부 근육 점수표가 아직 초안 — 트레이너 검수 반영 후 정확해짐. 적용 전 미리보기로 사용자가 확인.
무료와 차이가 안 느껴짐기능마다 무료 맛보기 + 잠금 한 줄을 그 자리에 둔다.
