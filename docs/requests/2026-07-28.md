  - ✅ **백필 실행 완료(2026-07-28)** — 이름 빈 프로필 10건 중 메타데이터에 이름이
    있는 **1건(구글 simbonggyo@gmail.com → "심봉교") 채움**. 나머지 9건은 전부
    이메일/비번 가입 계정이고 metadata 에 이름 자체가 없어(sub·email 만) 채울 값이
    없다 — 소셜 가입자는 아님. 사용한 SQL(재실행해도 빈 이름만 건드림) →
    ```sql
    update public.profiles p
       set name = nullif(trim(coalesce(
             u.raw_user_meta_data->>'name',
             u.raw_user_meta_data->>'full_name',
             u.raw_user_meta_data->>'user_name',
             u.raw_user_meta_data->>'preferred_username',
             u.raw_user_meta_data->'kakao_account'->'profile'->>'nickname',
             '')), '')
      from auth.users u
     where u.id = p.user_id
       and coalesce(trim(p.name), '') = ''
       and coalesce(trim(coalesce(u.raw_user_meta_data->>'name',
             u.raw_user_meta_data->>'full_name',
             u.raw_user_meta_data->>'user_name',
             u.raw_user_meta_data->>'preferred_username',
             u.raw_user_meta_data->'kakao_account'->'profile'->>'nickname','')), '') <> ''
       and coalesce(u.raw_user_meta_data->>'name', '') not like '%@%';
    ```
