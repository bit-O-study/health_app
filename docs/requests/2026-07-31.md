## 결정사항 / 메모

- Vercel 리전 `icn1`(서울) ↔ Supabase `ap-southeast-1`(싱가포르) — 왕복 1회당 약 70~90ms.
  왕복 **수**를 줄이는 것이 가장 효과가 크다(SQL 튜닝이 아니라).
- 이번 변경의 운영 P75 개선폭은 **배포 후 Speed Insights 신규 표본으로 확정**해야 한다.
  배포 전 추정치는 적지 않는다.
- `window.Capacitor` 는 **앱 판별 근거가 아니다** — `@capacitor/core` 를 import 하면
  웹 브라우저에도 주입된다(`platform: "web"`). 앱 판별은 `isNativeApp()`(UA 표식 또는
  `isNativePlatform()`) 하나로만 한다. 새 코드에서 `!!window.Capacitor` 를 다시 쓰지 말 것.
- E2E 가 간헐 실패하면 "원래 흔들리는 테스트"로 넘기기 전에 **HEAD 에서도 같은 비율로
  실패하는지** 먼저 재현해 볼 것. 이번 ② 케이스는 실제 앱 버그였다.
