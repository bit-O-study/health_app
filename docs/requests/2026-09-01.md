  안에 있어서, 추천 버튼 하나 때문에 편집기가 목록 274 KiB 를 끌고 왔다.
  (카탈로그가 재수출 → 기존 import 경로는 그대로)
- **`focusForExerciseId`** — 목록 없이 대표 부위. 카탈로그판과 **전 종목 동치**를 테스트로 고정.
- **`FOCUS_KEYS`/`isFocusKey`** — 서버 액션 입력 검증(카탈로그 부위 목록과 동기화도 테스트).

설계 원칙: **서버는 "어떤 운동인가"만 고르고, 처방(세트·횟수·무게)과 기구 선택
