### ② `c9ed940` 응답 보안 헤더 — 지금까지 **하나도 없었다**

`X-Frame-Options: SAMEORIGIN` · `X-Content-Type-Options: nosniff` ·
`Referrer-Policy: strict-origin-when-cross-origin` · `Permissions-Policy` ·
`Strict-Transport-Security`(프로덕션만).

- 권한 정책은 **쓰는 것만 self**: 카메라·위치·가속도·자이로. **마이크는 닫았다** —
  모든 `getUserMedia` 가 `audio:false` 다. 결제도 닫았다(네이티브 Play Billing).
- HSTS 를 로컬(http)에 걸면 브라우저가 localhost 를 https 로만 열려 **개발 서버가
  안 뜬다**(한 번 걸리면 브라우저 설정에서 지워야 풀린다) → `NODE_ENV` 로 갈랐다.
- **CSP 는 일부러 뺐다.** Next 하이드레이션 부트스트랩과 `ThemeScript` 가 인라인
  script 라 nonce 없이 `script-src` 를 조이면 **앱이 통째로 하얗게 뜬다.**
  `unsafe-inline` 을 허용한 반쪽 CSP 는 지키는 게 거의 없으면서 지킨다는 착각만 준다.
  → **nonce 미들웨어를 세울 때 한 번에 넣는 별도 작업**으로 남긴다.
- 헤더 표는 순수 모듈로 분리해 단위테스트로 의도를 못 박았다(빠져도 화면은 멀쩡해서
  아무도 모르는 종류의 회귀다). E2E 로 실제 응답에 붙는지도 확인.
