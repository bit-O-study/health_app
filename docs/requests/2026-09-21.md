### ⚠️ 오늘 배운 것 (다음에 또 걸림)

1. **Next dev 오버레이가 하단탭 클릭을 가로챈다.**
   `<nextjs-portal>` 이 화면 왼쪽 아래에 떠서 `intercepts pointer events` 로 30초 재시도 후 실패.
   프로덕션엔 없는 개발 도구 → `tests/e2e/helpers/dev-overlay.ts` 의 `silenceDevOverlay()` 로
   포인터 이벤트만 끈다. **9/20 남은 E2E 7건 실패도 이게 원인일 수 있다 — 확인해 볼 것.**
2. **E2E 그룹 이름이 실행별로 격리돼 있지 않았다.**
   이메일만 `E2E_RUN_ID` 로 격리돼 있고 그룹 이름은 고정 문자열이라,
   Codex 와 동시에 E2E 를 돌리면 `where name='E2E 주간분석'` 이 2건을 물어 왔다.
   → `run-scope.ts` 에 `scopedName()` 추가.
3. **미래 날짜로 완료 기록을 심으면 화면마다 숫자가 갈린다.**
   `seedCompletion({ dayOfWeek: 2 })` 는 이번 주 수요일이라 **월·화엔 미래**가 된다.
   트레이너 쪽(`getGroupMemberWeeklyTraining`)엔 `.lte("for_date", today)` 가 있고
   회원 본인 화면엔 없어서, 같은 주 월·화에만 "트레이너가 같은 숫자를 본다" 가 깨졌다.
   → 월요일(0)로 심어 날짜에 안 흔들리게. (제품 쪽 불일치 자체는 그대로 둠 — 미래 완료 기록은
   원래 생길 수 없는 상태라 급하지 않다. 정리하려면 별도 요청으로.)

- **(2) "E2E 7건도 그 오버레이 문제인지 확인해줘"** — ✅ 조사 완료(코드 변경 없음).
  - **결론: 오버레이 문제가 아니다.** 실패 리포트 어디에도 `nextjs-portal` 이 없다.
    전부 DB 값이 안 맞는 단언 실패다.
  - 현재 실패는 **7건이 아니라 4건**이다. `guided-complete-reenter` 2건은 지금 통과한다.
    남은 건 `arm-routine-swap` 3 + `workout-substitute-today-only` 1.
  - **진짜 원인(실험으로 확정): 확인 모달이 서버액션보다 먼저 닫혀서 액션이 취소된다.**
    - 증거: `POST http://localhost:3000/plan` 가 `net::ERR_ABORTED` 로 끊긴다.
      끊긴 뒤 `routine_exercises.day_index` 도 `custom_week` 도 **하나도 안 바뀐다**
      (before/after 스냅샷이 완전히 동일).
    - 경로: `ConfirmDialog.onConfirm` 이 `doSwapArmRoutine(...)` 을 부르고 **곧바로
      `setConfirm(null)`** → `useBackClose` 가 `history.back()` 을 예약 → 그 이동이
      아직 날아가는 중인 교환 POST 를 끊는다. (`plan-editor.tsx` 의 ConfirmDialog 부분)
    - **9/20 '원인 C'와 같은 계열**이다. 그때 5곳(전체 바꾸기·부위 추가·런닝 대체·런닝 유지·
      운동 등록)을 고쳤는데 **팔 교환만 빠졌다.**
    - 확인 실험: `arm-swap` 일 때 `setConfirm(null)` 을 안 하도록 바꾸니 **그 테스트가 통과**했다.
      단 그 방식은 "확인 후 모달이 닫힌다"를 기대하는 다른 테스트를 깨뜨린다
      (`교환 확인 모달은 배경을 inert…`, `미저장 팔 편집은 …차단된다`). **실험 패치는 원복함.**
  - 제대로 고치려면: 모달은 닫되 **액션이 날아가는 동안엔 뒤로가기 이동을 막는**
    방식이 필요하다(예: in-flight 중엔 `useBackClose` 의 history 복원을 미루기).
    이건 `modal-history.ts` 를 건드리는 일이라 **별도 요청으로 받는 게 안전하다.**
  - 아직 원인 미확인: `workout-substitute-today-only` 1건(`daily_plan` 이 빔).
    같은 경쟁일 가능성이 높지만 확인 안 함.
