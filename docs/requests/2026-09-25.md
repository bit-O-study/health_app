**제어 컴포넌트 + 하이드레이션 지연**이다. 서버 HTML 이 보이는 동안 타이핑하거나
비밀번호 매니저가 자동완성하면 값이 DOM 에만 들어가고(onChange 미부착),
**화면엔 멀쩡히 보이는데** 제출하면 "이메일과 비밀번호를 입력해 주세요" 가 떴다.

고침: DOM 에만 있는 값을 마운트 직후 끌어올리고(`lib/forms/prefilled.ts` +
`use-prefilled-inputs.ts`), 제출은 폼 DOM 의 실제 값으로 한다. 핸들러가 붙기 전엔
`<fieldset disabled>` 로 아예 막는다(두 겹). **인증 폼 4개 전부** 적용.
단위 15건 + E2E 4건(실계정 로그인 · 입력 이벤트 없는 자동완성 포함).
