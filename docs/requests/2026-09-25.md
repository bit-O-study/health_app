  ### 진짜 원인 — **하이드레이션 전에 입력하면 로그인 버튼이 먹통**

  프로덕션(`health-app-five-iota.vercel.app`)에서 재현했다.

  - 로그인 폼 입력은 전부 **제어 컴포넌트**(`value={state}`)다. 첫 화면은 서버 HTML 이고
    React 하이드레이션은 조금 뒤에 끝나는데, 그 사이에 타이핑하거나 브라우저·비밀번호
    매니저가 자동완성하면 값이 **DOM 에만** 들어간다(onChange 가 아직 안 붙었다).
  - 그래서 **화면엔 이메일·비밀번호가 멀쩡히 보이는데** 로그인을 누르면
    "이메일과 비밀번호를 입력해 주세요" 가 뜬다. 필드를 다시 건드리기 전엔 계속 안 된다.
  - 앱 WebView·느린 네트워크처럼 하이드레이션이 늦을수록 잘 걸린다.
    재현 로그: JS 청크를 6초 지연시키고 입력 → `[하이드레이션 후] email="bong9468@naver.com"`
