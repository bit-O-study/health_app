### (1) 고객센터 관리 화면을 통합 관리자 콘솔로 이전

요청: "헬쑤 고객센터 관리가 헬쑤 어드민(앱 내부 `/admin`)에 만들어져 있다 — 통합 로그인 콘솔로 바꿨었는데?"
확인: 9/25 `74351af` 에서 문의 관리 화면을 앱 내부 `/admin/support` 에 넣었다. 관리자는 7/22부터
통합 콘솔 `heltch-admin`(https://heltch-admin.vercel.app)을 쓴다 → 콘솔로 옮김.
콘솔 저장소는 사용자가 `C:\git\admin` 으로 클론.

- **콘솔(`C:\git\admin`, 브랜치 `feat/health-support`)** — `/admin/health/support` 목록(미확인 수·상태/종류/기간/내 담당
  필터·검색·페이지) + `/admin/health/support/[id]` 상세(처리 상태·우선순위·담당, 답변, 관리자 전용 메모, 첨부 사진,
  진단정보, 처리·발송 이력). 사이드바 헬쑤앱 → "고객센터". 관리자 세션으로 `support_*` RLS·RPC 를 그대로 사용,
  첨부 사진만 service_role 서명 URL. 테스트 `tests/support-model.test.ts`·nav 테스트 추가, vitest 65/65, tsc·next build 통과.
- **헬쑤앱(브랜치 `feat/support-admin-console`)** — 옛 `/admin/support`, `/admin/support/{id}` 는 `next.config.ts`
  redirects 로 콘솔 같은 화면에 307(이미 받은 카카오 알림 링크 보호). 카카오 메시지·기기 푸시 링크를 콘솔 주소로.
  앱의 관리자용 코드(ManageForm·manageTicket·관리자 목록/상세 분기) 제거, 회원 화면만 남김.
  카카오 연결(`/admin/support/notifications`)은 OAuth 리다이렉트가 앱 도메인에 등록돼 있어 앱에 남김 + 콘솔 이동 링크.
  BE 2701/2701, tsc 통과, E2E `customer-support.spec.ts` 통과.

**결정**: 카카오 알림 연결 화면은 헬쑤앱에 남긴다(콘솔로 옮기려면 카카오 Redirect URI·REST 키·암호화 키를 콘솔에도 설정해야 함).
