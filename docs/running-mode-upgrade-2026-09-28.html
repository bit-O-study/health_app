기록 화면은 갖췄는데, 달리는 동안과 끝나는 순간이 비어 있습니다.

런닝 기록(월 요약·상세·경로·1km 구간)은 9/27에 갖춰졌습니다. 그런데 그 기록이 만들어지는 과정 — 달리는 중과 종료 순간 — 은 초기 상태 그대로입니다. 일시정지·카운트다운·음성 안내가 없고, 종료는 확인 없이 한 번에 끝나며, 저장이 실패하면 기록이 영구히 사라지고, 터널에서 GPS가 15초 끊기면 달리기 자체가 끝납니다. 이 보고서는 먼저 데이터를 잃지 않게 하고, 그 위에 달리는 경험(목표·안내·일시정지)과 끝난 뒤(요약·기록·개인 최고)를 얹는 순서로 설계합니다.

지금 흐름

빨간 칸이 끊기거나 비는 곳입니다.

운동 탭 “런닝” / 런닝 기록 “런닝 시작”→실내 · 야외 선택→권한 확인→바로 시작 (카운트다운 없음)→달리는 중 (일시정지·안내 없음)→종료 한 번 = 즉시 종료→“런닝 완료 🏁 · 확인”→인트로로 되돌아감 (기록 링크 없음)

/jog 정리

실내 런닝과 겹치는 힐링 러닝은 기록 연결 또는 제거 — 결정 5.

—

단계

한 단계씩 커밋·테스트. 단계 1은 화면 변화가 거의 없습니다.

1 · 데이터 안전 (2일)

잃지 않게

  • 저장 후 삭제 + 재시도 큐
  • GPS 오류 = 멈춤
  • 저장 한 곳 + 파생
  • 표기 함수 통일
2 · 달리는 중 (2일)

기본기

  • 카운트다운 · 일시정지 · 자동 일시정지
  • 꾹 눌러 종료
  • Wake Lock · GPS 신호
  • 지금 페이스 · 3D 켬/끔
3 · 목표·안내 (2–3일)

같이 달리는 느낌

  • 거리·시간 목표 + 진행 막대
  • 1km 음성·진동 안내
  • 종료 요약 한 줄 + 기록 바로 가기
  • 개인 최고 배지
4 · 프로그램 (3일+)

꾸준히

  • 걷기+달리기 단계 프로그램(런데이식)
  • 주간 목표 · 연속 주
  • Health Connect 운동 세션 기록

진행 전에 정해 주실 것

추천을 표시해 두었습니다.

1. 종료 화면

지금처럼 “완료 · 확인”만대신 확인 뒤 기록 화면으로 이동.

2. 음성 안내 기본값

켜짐 (1km마다, 짧게)이어폰 없이 스피커로 나가는 걸 싫어하면 시작 화면에서 바로 끌 수 있게.
