적용 순서

토큰을 먼저 바꿔야 뒤의 교체 작업이 한 번으로 끝납니다. 단계마다 커밋하고, UI 단계는 E2E를 같이 돌립니다.

  1. 토큰 연결 · 폰트 로드globals.css, layout.tsx

    브랜드/회색/의미색을 Tailwind 클래스로 쓸 수 있게 하고 Pretendard를 실제로 불러옵니다. 화면 변화는 작고 위험도도 낮습니다.

  2. 홈 재구성home 카드 7개

    배너 하나로 합치기, “오늘” 카드로 다짐+식단 합치기, “이번 주” 카드 하나로 합치기, 광고 맨 아래로. 날씨 배경은 결정에 따라 제거합니다.

  3. 카드 · 글자 일괄 정리~150 파일

    .app-card 통일, 임의 글자 크기 치환, font-black 제거. 기계적인 치환이 대부분이라 파일 단위로 나눠 커밋합니다.

  4. 공통 헤더 · 페이지 틀탭 화면 6개

    운동·식단·캘린더·그룹·커뮤니티·설정에 같은 헤더와 폭을 적용합니다. 운동 탭에서 홈과 겹치는 주간 카드 2개를 1개로 줄입니다.

  5. 커뮤니티 · 설정 소음 제거community-board, settings

    그라데이션 제목·버튼, 자홍 포커스, 설정의 4색 아이콘 칩을 걷어내고 설정 12행을 공통 행 컴포넌트로 바꿉니다.
