M1

휴식이 “상태”가 아니라 “카드 한 장” 심각

세트를 완료하면 영상 위에 휴식 카드만 뜨고, 아래 패널은 세트 중과 똑같습니다. 휴식 중에도 세트 완료 슬라이더가 살아 있어 쉬다가 밀면 다음 세트가 바로 기록되고, 휴식 프리셋 5개도 그대로 보입니다. 쉬는 동안 필요한 것(남은 시간, 방금 세트 실제 횟수, 다음 세트 무게)은 따로 없습니다.
