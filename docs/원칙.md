# 원칙 (PRINCIPLES) — 법(法). 절대 바꾸지 말 것.

> 이 문서는 **법**이다. Claude 는 **모든 요청/질문을 처리하기 전에 이 문서를 먼저 읽고**,
> 여기 적힌 원칙을 **반드시 지킨다**. 이 문서의 내용은 **사용자만** 바꿀 수 있고,
> Claude 는 임의로 수정·삭제·완화하지 않는다. (원칙 추가는 사용자가 지시할 때만.)

## 원칙 목록

1. **오늘만 운동 변경 ↔ 운동탭 편집의 편집 가능한 부위는 동일해야 한다.**
   "오늘만 운동 변경" 안에서 편집할 수 있는 운동 부위는, 운동탭(운동 편집)에 들어가서
   편집으로 바꿀 수 있는 운동 부위와 **똑같아야** 한다. (두 편집 화면이 서로 다른
   부위 집합을 보여주면 안 된다 — 항상 일치.)

2. **오늘만 운동은 루틴(영구 루틴)에 절대 영향을 주면 안 된다.**
   "오늘만" 으로 하는 모든 변경(부위 추가·전체 바꾸기·직접 담기·휴식 전환 등)은 **오늘 하루
   (daily_plan/daily_conditioning 등)에만** 반영되고, 영구 루틴(routine_exercises·user_routines
   의 custom_week 등)은 **건드리지 않는다**. 내일부터는 원래 루틴 그대로 돌아와야 한다.
